# Security policy

Do not report secrets or user book content in public issues. Do not commit `.env`, PDFs, extracted
artifacts, page images, JSONL exports, or provider credentials. The default CLI has no network
clients. If a future optional provider adapter is added, it must be explicitly named, isolated from
the base install, fail closed, and document its data transmission.

For a security report, contact the repository owner privately through GitHub rather than attaching
reproduction material containing a source book or credential.
