# Elec Codebook OO v0.7.0

- Added local, deterministic configuration candidates for edition, printed-page offsets, semantic
  ranges, OCR policy, and coarse layout characteristics.
- Each candidate is separated from observed facts and includes confidence plus evidence counts.
- Candidates never silently become profile authority: edition, page mappings, and content ranges
  still require explicit operator confirmation.

This release remains local-first by default: source inspection returns no extracted text, makes no
network or provider calls, and writes profiles only behind `--apply`.
